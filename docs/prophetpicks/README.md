# ProphetPicks

ProphetPicks is a private, probability-first sports parlay research dashboard.

Primary slogan:

```text
Find the edge before the slip.
```

The first design direction is a dense Command Center UI with a pharaoh-mask brand identity, a today slate board, leg reasoning drawer, slip risk rail, and prediction journal. ProphetPicks is intended as personal decision support, not guaranteed betting advice or automated bet placement.

Current app scope:

- NBA player props demo slate.
- Soccer match markets normalized through an API-Football adapter.
- Local/server-side soccer sync via `APIFOOTBALL_KEY`.
- Browser UI consumes normalized data only, not provider secrets.
